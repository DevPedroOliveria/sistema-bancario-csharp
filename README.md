# 💰 Sistema Bancário em C#

Projeto de console desenvolvido em C# para simular operações bancárias.

## 🚀 Funcionalidades

- Criar conta
- Depositar
- Sacar
- Ver saldo
- Extrato com histórico
- Persistência em JSON

## 🛠 Tecnologias

- C#
- .NET
- System.Text.Json

## 📚 Aprendizados

- Manipulação de listas
- Programação orientada a objetos
- Tratamento de erros
- Persistência de dados

```bash
dotnet run
